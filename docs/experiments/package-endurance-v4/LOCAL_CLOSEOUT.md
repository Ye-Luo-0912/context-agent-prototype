2026-09-20，用户要求“继续完成全部任务”。接手时原四小时供应商窗口已经到期。
该窗口的创建时间、截止时间、96 主决策/128 attempts/估算 USD 1 上限、账本和
原模型文件均保留；不创建替代付费窗口，不发送新的供应商请求，不清除 Core
对不确定进程副作用的恢复围栏，不重复执行旧效果。

本次完成独立的零供应商本地工作：核对旧费用与保护文件；在新副本上验证已有
assisted 实现；修复实际暴露的缺陷；执行公共 smoke、独立 oracle、双平台脚本与
受影响 Rust 检查；归档真实结果。仓库提交、推送和 release 不在本轮范围。

`load.py --local-only` 是独立副本的本地验收入口。默认入口仍要求原 campaign 的
有效期限。本地入口不读取凭据或账本，不启动模型，仍要求当前候选与独立验收
文件摘要完全匹配，最多 300 秒负载及 180 秒启动/故障探针/清理窗口。回执标明
`standalone_local_only` 和 `assisted_application_load`，不能算作旧 campaign 内完成
负载，也不能算作模型自主交付。过期 campaign 的默认调用仍有拒绝回归。

所有模型产物、人工修改与失败/成功回执分开保留。最终结果见
[收尾回执](CLOSEOUT_2026-09-20.md)。
