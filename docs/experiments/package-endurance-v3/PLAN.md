2. 形成明确标为 assisted 的可运行应用基线：旧回执重放不回退当前部署，

3. 新 Runtime 组合回归：部分工具效果已完成，另一操作在途时取消，

4. 公共 host 连续旅程：真实工具读写/进程、审批、长纠正、任务切换、

5. 真实模型执行一个有明确独立验收的小切片，避免再次花满额度重建已修好的应用。
   原始响应/usage 和 Runtime 事件留存；若任何安全或预算门禁失败则停止该分支。
6. 前置验收通过后，4 个 worker 与 GC 真实重叠运行 30 分钟，

   负载产物绑定具体源码摘要，不能用旧 PASS 证明新源码。

## 停止与交付

权限越界、不确定效果盲重放、跨任务采用、虚假持久化停止对应副作用分支，
保留证据后修复；只有明确修复并通过对应反例才恢复新副本上的相关运行。
普通应用/控制器缺陷可在本轮范围内修复，回执写明人工贡献。
交付记录 fired/observed/verdict、完整用量、独立磁盘验收、进程清理、
实际优化前后差异及未触发项；不把计划、文字 PASS 或普通 final 当完成证明。
