The repair adds one actor-local `pending_failed_turn_checkpoint` continuation.
When an older idle GC or completion boundary owns the single `gc_work` lane, the
failed-turn path first creates the required `FailedTurnYield` checkpoint debt,
then records its continuation and returns to the actor loop. After the older
operation completes, the same actor retries the normal checkpoint relay. It does
not overwrite the older owner, start another scheduler, or discard the latest
directive. `ensure_idle` refuses a new mutation while this parked continuation
or its safe-point commit is still settling. A cancellation leaves the admitted
checkpoint preparation to land but cannot publish a second `TurnFailed` after a
durable `TurnCancelled`.
