# Flash 实际工具链走查：固定任务

2026-09-11；执行前固定。入口为当前工作树构建的 `agent-tui` 无头模式，DeepSeek `deepseek-flash`，Responses、`reasoning.effort=none`、原生默认缓存、dynamic Context。这是一轮当前版本基线；没有旧版本对照，不作降本因果结论。

使用三个独立 Git 工作区，代码来自本仓库 `scripts/doc_consistency.py`。这是来源于真实代码的隔离任务样本，不是修复用户工作树的实际待办，也不等同于大型整仓开发或模型总体成功率。

| 样本 | 起点和目标 | 固定验收 | 预算 |
|---|---|---|---|
| A 跨模块修改 | 将真实脚本的 Markdown 链接校验提取至 `scripts/doc_links.py`，原 `check_links(violations)` 委托调用，其他检查保持 | 9 类行为检查不回退；新增函数可独立调用；旧入口实际委托；测试与其他源文件不改动 | 最多 12 主模型轮，300 秒 |
| B 多项验收 | 原脚本保持只读，执行九类链接行为检查并输出结构化结果 | 本地可信测试 9/9；`validation.json` 含九个检查域及真实 PASS，原脚本与测试不变 | 最多 8 主模型轮，240 秒 |
| C 长输出与中断恢复 | 原脚本加输出大日志的可信测试；首段强制读后在轮次预算处保存，冷恢复段在 1 秒等待上限中断，第三进程恢复并读取日志后部标记 | 实际工具输出超过 3 MiB；末端标记被正确写入 `summary.json`；已验证快照跨进程恢复；无源码/测试修改、无重复写入副作用 | 主模型轮 1 + 4 + 12；等待上限 120 + 1 + 300 秒 |

九个检查域：已有相对路径、缺失路径、缺失文档、外链跳过、百分号编码、fragment、嵌套相对路径、中文路径、混合有效/无效链接。B 是九类可执行应用检查，**不是九份 host 声明的独立 VerificationCoverageDeclaration**；W05 的九域证明保留不由这个样本替代。

每次模型响应最多 2,048 输出 tokens；使用产品现有每请求最多 3 次尝试，重试单独记录。维护沿现有每次最多 4 个 compactor 调用的上界；全部决策与维护 usage 分开统计。不自动重跑失败样本或增加轮次。外层进程期限为对应等待上限加 45 秒；超过期限按未知中断失败记录并清理本次进程树。

写权限仅覆盖 A 的 `scripts/`、B 的 `validation.json`、C 的 `summary.json`；进程授权只允许固定绝对 Python 路径的 `-m pytest` 前缀，最多 4 次、30 分钟到期。密钥仅从进程输入取得，不进入任务、Git、报告或模型可读文件。

保存运行前源码摘要、二进制摘要、任务起点 commit、prompt、授权范围、运行 JSONL、重试记录、最终 diff、可信验证结果及快照。普通 final 仍为待操作员审阅。取消精确请求时间若未在产品事件中暴露则标为不可测，不拿总耗时冒充取消回执延迟。维护调用没有 usage 时记缺测，不按零消耗记账。
